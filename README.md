Credit Score Prediction Dashboard

Overview

This is a multi-page interactive dashboard built with Dash and Plotly that allows users to explore and predict credit scores based on various financial and demographic inputs.
The dashboard includes data visualizations and a credit score prediction interface.

Features

Data Exploration: Visualizations of key financial and demographic features.

Interactive Filters: Users can select and compare different features.

Credit Score Prediction: Users can input financial details to predict their credit score (Standard, Poor, Good) using a machine learning model.
How the Credit Score Prediction Works

The user inputs personal and financial details (e.g., age, income, number of loans, credit utilization ratio).

The app preprocesses the inputs and passes them to a trained machine learning model.

The model predicts the credit score category and displays the result in real time.
